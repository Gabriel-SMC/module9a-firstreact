# Module 9A - Build Your First React Component

## Description
This is a React app created using Vite that renders a UserProfile component. The component includes a name, bio, and image styled with inline CSS.

## What I Learned
- How to set up a React project using Vite
- How to write and structure a functional React component
- How to use JSX and inline styles
- How to render a component in App.jsx

## Challenges
- Had ran into a situation where every time I finished up a code, it would result in syntax errors and the React app would not function. To solve it, I had to restructure a great portion of the code to ensure it worked again.
- Colors were all white like the background and made the text nearly impossible. Selected different colors so they are readable.
